# Импульс

Короткая браузерная аркада про дрон-курьер. Пройди 12 ворот за один заезд.

Зажми пробел или кнопку «Зажми, чтобы зарядить», чтобы набрать высоту, и отпусти в нужный момент. Пунктир показывает траекторию, светлая подсветка подсказывает окно. Ворота движутся, поэтому считай время полёта. В браузере сохраняются личный рекорд по числу пройденных ворот и лучшее время полного заезда.

Игра не требует регистрации, сервера приложения или внешних ресурсов. Для запуска отдайте содержимое игрового ZIP обычным статическим HTTP-хостом.

## Разработка

Цель и критерии пилота ведём в GitHub Issue, изменения идут через ветку и draft PR. GitHub Actions проверяет игровую модель, собирает ZIP и запускает Chromium непосредственно из распакованной сборки. Релизные ZIP и контрольную сумму храним в черновике GitHub Releases. CI не публикует игру, не загружает её на площадки и не использует Actions Artifacts.
